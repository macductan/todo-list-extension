🛡️ Hướng dẫn tạo Fine-grained Personal Access Token an toàn
  1. Mở GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Nhấn Generate new token, đặt tên gợi nhớ và chọn thời hạn hiệu lực phù hợp.
  3. Tại mục Repository access: Chọn "Only select repositories" và chỉ chọn đúng 1 repository riêng biệt dùng để lưu dữ liệu công việc.
  4. Tại mục Permissions → Repository permissions: Chỉ cấp quyền Contents: Read and write (giữ tất cả quyền khác ở mức No access).
  5. Sao chép mã Token vừa tạo và dán vào ô mật khẩu phía trên. Tuyệt đối không dùng Classic Token cấp toàn quyền repo.
